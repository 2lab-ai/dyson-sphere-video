## The mechanism (read `app/src/engine/world.ts` first)

A **run** is one world rendered by ONE host module across consecutive plates (NIGHT = `scenes/wall.ts`, FILM = `film.ts`,
COSMOS = `space.ts`, ORBIT = `limb.ts`, LINES = `lines.ts`, AMBER = `amber.ts`). The host extends `WorldHost`:

- `renderWorld(f, out)` — the persistent world every frame (same medium, ground, camera class, layout for every plate of
  the run; the camera motion per bar is the run's, e.g. NIGHT "eye-level, push per bar").
- `slot(f)` — where the subject goes (Compositor uv `scale`/`offset`) and the blend: `'screen'`/`'max'` for a dark-ground
  subject on a dark world, `'multiply'` for a light subject on a light world, `'normal'` for a premultiplied child.
- `afterSubject(f, out)` — optional foreground pass (hardware silhouettes in front, grain, vignette, the beat snap).

The **subject** is an existing `scenes/<module>.ts` (chosen per plate in edit.json). The host constructs it with
`ctx.params.hosted = true` and `params.variant = subject.variant`, renders it into a private target, and composites it.
So a subject module keeps everything it does — its object, its shots, its `drawLyric` call — but when `params.hosted`
is true it must:
1. **not paint its own world/ground** (clear its target to transparent black `clearRT(r, out, [0,0,0], 0)` or, for a
   light world, to white with alpha 0 — whatever makes the blend mode in `slot()` drop the background);
2. **draw the subject centred** in its own frame (the host places it with the slot uv transform);
3. **draw the lyric on the subject** (`drawLyric`, ≥120 px — `LYRIC_MIN_PX` in `engine/lyric.ts` now floors it; the
   line belongs to the object: printed on it, lit by it, occluded by it — never a floating caption);
4. keep its beat call(s) (`beatPulse`/`kickPulse`/`downbeatPulse` from `engine/beat.ts`; the gate's `C.beat-call`).

A standalone plate (no host) is a normal scene, as in v3.

## Rules that the gate and the reviewer check

- **Typing is literal.** For a `nov: 2` plate, the four kept dims are code: the host draws them. Only `dims.S` changes.
  For a `nov: 1` plate, `residue` names the one thing carried from the previous run — make it visible in the first bar.
- **Hits persist.** A beat hit is a change that stays ≥6 frames (a cut-in 1.5–2.5×, a ≥20 px jolt, an object state
  flip). No single-frame flashes. **Full-frame whiteouts only at 65.120 (p13), 142.035 (inside p29), 165.343 (inside p33),
  and p37's bomb.** Every bar needs a visible accent; every beat a visible mark on the subject.
- **Lyrics: stamp, not fill.** A syllable's orange arrives at its own start as a state flip (sung = orange), not a
  running wipe across the glyph; glyphs never re-layout mid-line; no text on instrumental plates (`lines: []`).
- **No graticule / axis / diagnostic UI** anywhere in NIGHT, FILM, LINES (the "도면" look the owner rejected twice).
- **Ground class is measured.** `look.ground` (dark/mid/light) must match what the frame's mean luminance says at the
  cut: a "light" plate is really light (AMBER p32–p34 are all light; p40/p42 stay dark with bright subjects).
- Deterministic f(t) — no `Math.random()` without a seeded `hash()`; no per-frame allocation storms.
